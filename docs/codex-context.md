# Codex 작업 연속성

## 프로젝트 목적

Windows 10/11에서 한 사람이 행사별 준비 업무를 관리하는 Python/PySide6 데스크톱 앱이다. 행사명과 날짜로 기본 업무의 작업기간·마감일을 생성하고 체크리스트, 진행률, 달력, 백업·내보내기를 제공한다.

## 2026-08-10 구현 결과

- 기본 항목 표에 확인 포인트 다음으로 수량, 단위, 업체, 담당을 배치했다. 추가·수정·삭제를 지원하며, 기본 업체·담당도 새 행사 작업에 복사한다.
- 데이터베이스 스키마를 v2로 올렸다. 기존 v1 DB는 실행 시 기본 업체·담당 열을 자동 추가하며, 마이그레이션 전에 안전 복사본을 만든다.

## 2026-08-10 v0.2.0 개선

- 실제 사용자 행사 `2026-08-10~2026-10-02`가 기존 규칙에서 4월부터 시작되던 원인을 확인했다. 시작일을 행사 당일로 보고 D-120을 빼던 의미 불일치가 원인이었다.

- DB 스키마 v3에서 기존 자동 일정만 새 규칙으로 재계산한다. 수동 일정은 보존하며 `event_checklist.pre-v2.db` 안전 복사본을 먼저 만든다.
- 대시보드의 파란 교차 줄을 제거하고 지연/임박 업무를 의미 기반 옅은 경고색으로 표시한다.
- 모든 스크롤바, 탭, 표 머리의 빈 영역을 밝은 테마로 통일했다.
- 행사·기본 항목·담당/업체 표는 모든 열 너비를 직접 조정·이동할 수 있고 `열 너비 맞춤`을 제공한다.
- 기본 항목은 더블클릭 대화상자 없이 모든 표시 필드를 표에서 바로 편집한다.
- 달력은 개별 업무 기간을 얇은 다중 박스로 표시하고 우측 목록을 카드형 정보 구조로 재구성했다.
- 자동 테스트 20개 통과. 실제 사용자 DB 복사본 v2→v3 이전, 안전 복사본, 준비 시작일 이전 일정 제거, PyInstaller 배포본 기동과 달력 렌더를 확인했다.

## 2026-08-10 v0.2.1 달력 가독성 개선

- 달력의 얇은 기간 박스 안에 작은 글씨의 업무명을 표시한다.
- 날짜별 표시 순서는 미완료 우선, 마감일이 가까운 순서, 우선순위, 기본 순서다.
- 셀에는 최대 네 줄만 사용하며 초과 업무는 `+N개 더보기`로 표시한다. 날짜를 선택하면 오른쪽 카드 목록에는 전체 업무가 그대로 나온다.
- 일정이 많은 날에도 날짜 숫자가 가려지지 않도록 업무가 있는 셀의 날짜를 위쪽에 고정해 다시 그린다.
- 자동 테스트 21개 통과 및 실제 행사 DB 복사본으로 달력 라벨·더보기·전체 우측 목록을 렌더 검증했다.

## 주의사항

- 실제 사용자 DB를 초기화하거나 기본 데이터로 다시 덮어쓰지 않는다.
- 백업 복원 전 현재 DB를 반드시 별도 백업한다.
- 기본 일정표는 일반 행사 기준 초안이며 법정 신고·허가 기한을 보증하지 않는다.

## 2026-08-11 v0.3.6 자동 업데이트 재실행 수정

- v0.3.4에서 업데이트 버튼을 누르면 앱 종료 후 다시 실행되지 않는 현상을 재현했다. 생성된 `apply-0.3.5.ps1`과 남은 staging 폴더를 확인했다.
- 원인은 업데이트 PowerShell이 설치 폴더를 현재 작업 폴더로 상속받아, 자기 자신이 사용 중인 설치 폴더를 `Move-Item`으로 교체하지 못한 것이다.
- PowerShell 작업 위치와 Python `Popen.cwd`를 `%LOCALAPPDATA%\EventCheckList\updates`로 고정했다.
- 압축 해제부터 새 앱 health 확인까지 전체 과정을 하나의 복구 범위로 묶었다. 교체 전 실패도 기존 앱을 다시 실행하며 `update-버전.log`에 단계와 오류를 기록한다.
- 격리된 실제 설치 폴더 복사본에서 성공 경로는 `EXTRACT→SWAP→LAUNCH→SUCCESS`, 잘못된 ZIP 실패 경로는 `FAILED→RECOVERY`와 기존 앱 재실행을 확인했다.
- 기존 v0.3.4 업데이터 자체에는 수정 코드를 소급할 수 없어 v0.3.6을 한 번 수동 복구 설치했다. 다음 v0.3.7은 v0.3.6의 인앱 업데이트 버튼으로 설치·재실행을 실제 검증하기 위한 릴리스다.
