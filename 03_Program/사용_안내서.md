# 이벤트 체크리스트 사용 안내서

## 실행

`dist/EventChecklist/EventChecklist.exe`를 더블클릭합니다. Python을 별도로 설치할 필요가 없습니다.

처음 실행하면 사용자 데이터 폴더에 데이터베이스와 자동 백업 폴더가 만들어집니다.

## 첫 행사 만들기

1. 대시보드 또는 행사 화면에서 `+ 새 행사`를 누릅니다.
2. 행사명과 `준비 시작일`, `최종 행사일`을 입력합니다.
3. 장소, 주최/주관, 예산은 필요한 경우 입력합니다.
4. 기본 항목 120개가 모두 선택되어 있습니다. 이번 행사에 필요 없는 분류나 항목의 체크를 해제합니다.
5. `저장`을 누르면 준비 시작일부터 최종 행사일까지의 기간에 맞춰 작업이 일정순으로 자동 배치됩니다. 준비 기간이 D-120보다 짧으면 기본 일정을 같은 비율로 압축합니다.

## 체크리스트 사용

- 가장 왼쪽 체크박스를 누르면 즉시 완료 처리됩니다.
- 상태는 미착수, 진행중, 확인요청, 완료, 보류, 해당없음 중에서 선택합니다.
- 해당없음은 진행률 계산에서 제외됩니다.
- 날짜를 직접 바꾸면 해당 업무만 수동 일정으로 전환됩니다.
- 항목 행을 더블클릭하면 확인 포인트, 수량, 단위와 행사별 메모를 수정할 수 있습니다.
- 표가 화면보다 넓으면 아래쪽 가로 스크롤바로 비용·업체 열을 확인합니다.
- 모든 표의 열 경계를 드래그해 폭을 바꾸거나 열 제목을 끌어 순서를 바꿀 수 있습니다. `열 너비 맞춤`은 현재 창 크기에 맞게 열을 자동 정리합니다.

## 달력

- 날짜 칸 아래의 얇은 기간 박스는 해당 날짜에 진행 중인 개별 업무를 뜻합니다. 색상은 업무 분류와 완료 상태를 구분합니다.
- 기간 박스 안에는 업무명이 작은 글자로 표시됩니다. 미완료 업무 중 마감일이 가까운 항목이 먼저 나오며, 같은 마감일이면 우선순위가 높은 항목이 먼저 표시됩니다.
- 한 날짜의 업무가 표시 공간보다 많으면 `+N개 더보기`가 나타납니다. 해당 날짜를 누르면 오른쪽 목록에서 생략된 업무까지 모두 확인할 수 있습니다.
- 날짜를 누르면 오른쪽 카드에 행사명, 업무명, 작업기간, 상태와 D-Day가 표시됩니다.
- 위쪽 행사 선택에서 한 행사만 보거나 모든 행사를 함께 볼 수 있습니다.

## 기본 항목

- 기본 항목을 비활성화하면 이후 새 행사에서 제외됩니다.
- `+ 항목 추가`로 새 기본 항목을 만들 수 있습니다.
- 대분류, 중분류, 항목명, 확인 포인트, 수량, 단위와 일정 오프셋은 셀을 한 번 눌러 바로 수정할 수 있습니다.
- 업체, 담당, 기준일과 우선순위는 표 안의 선택 상자에서 바로 변경할 수 있습니다.
- 행을 선택하고 `선택 삭제`를 누르면 기본 항목에서 삭제됩니다. 이미 만들어진 행사의 업무는 그대로 유지됩니다.
- 기본 항목 변경은 이미 만들어진 행사에는 적용되지 않습니다.

## 기존 데이터 자동 보정

- 0.2.0을 처음 실행하면 기존 자동 일정을 준비 시작일~최종 행사일 기준으로 다시 계산합니다.
- 사용자가 직접 날짜를 수정해 `수동`으로 표시된 일정은 변경하지 않습니다.
- 변경 전 데이터베이스는 같은 데이터 폴더의 `event_checklist.pre-v2.db`로 안전 복사됩니다.

## 백업과 내보내기

- 앱은 하루 한 번 자동 백업합니다.
- 설정에서 수동 백업, 백업 복원, Excel/CSV 내보내기를 실행할 수 있습니다.
- 백업 복원은 현재 데이터를 교체하므로, 프로그램이 먼저 현재 상태를 안전 백업한 뒤 복원합니다.

## 데이터 위치

- 데이터베이스: `%LOCALAPPDATA%\EventCheckList\data\event_checklist.db`
- 자동 백업: `%LOCALAPPDATA%\EventCheckList\backups`
