# 행사 준비 체크리스트 자동화 시트 — 사용 안내서

## 1. 개요

첨부해 주신 `체크리스트.xlsx`는 대분류 5개(시스템·시설·행사·홍보·운영), 중분류 25개, 세부 항목 118개로 구성된 행사 준비 점검표였습니다. 다만 원본은 항목을 나열하고 손으로 표기하는 방식이었기 때문에 진행 상황을 한눈에 파악하거나 담당·마감을 관리하기 어려운 구조였습니다. 특히 `CHK` 열이 체크 표시용이 아니라 "모집 / 심사위원 / 상장 / 상금 / 부상"과 같은 확인 메모로 사용된 행이 섞여 있어, 그대로는 집계가 불가능했습니다.

이번 결과물은 원본의 항목 체계를 100% 그대로 유지하면서, **모든 관리 항목을 드롭다운으로 선택**하고 **진행률·마감·비용이 자동으로 집계**되도록 재설계한 스프레드시트입니다. Google 드라이브에 업로드하여 Google 스프레드시트로 열면 드롭다운(데이터 확인), 수식, 조건부 서식이 모두 그대로 동작합니다.

## 2. 시트 구성

| 시트 | 성격 | 설명 |
|---|---|---|
| **사용안내** | 참고 | 파일 사용법 요약 (시트 내부에 동일 내용 수록) |
| **대시보드** | 자동 | 진행률, 상태별·대분류별·담당별 집계, 마감 임박 목록. 직접 입력하지 않습니다 |
| **체크리스트** | 입력 | 실제 작업 시트. 118개 항목 사전 입력, 300행까지 확장 가능 |
| **행사정보** | 입력 | 행사명·일자·장소 등 기본 정보. 행사명은 다른 시트 제목에 자동 반영 |
| **설정** | 입력 | 드롭다운 원본 목록 관리 (대분류·중분류·상태·우선순위·단위 등) |
| **담당·업체** | 입력 | 담당자·협력업체 마스터. 입력하면 체크리스트 드롭다운에 자동 반영 |

## 3. 작업 순서

첫 사용 시에는 **행사정보 → 담당·업체 → 체크리스트** 순으로 채우시는 것이 가장 효율적입니다. `행사정보` 시트의 행사명(C3)과 시작일(C4)을 입력하면 체크리스트·대시보드 제목과 행사 D-Day가 자동으로 갱신됩니다. 이어서 `담당·업체` 시트에 실제 담당자 이름과 업체명을 적어 두면, 체크리스트의 담당·업체 열 드롭다운이 그 목록으로 바뀌므로 매번 이름을 타이핑할 필요가 없습니다.

이후 `체크리스트` 시트에서 항목별로 필요여부·진행상태·우선순위·담당·업체·마감일을 지정하시면 됩니다. 이번 행사에 해당하지 않는 항목은 삭제하지 말고 **필요여부를 "불필요"**로, 또는 **진행상태를 "해당없음"**으로 선택하십시오. 그러면 해당 항목은 진행률 분모에서 제외되면서 항목명이 회색으로 흐려져 시야에서 자연스럽게 빠집니다. 원본 체계를 보존하면서 행사별로 범위를 조절할 수 있는 방식입니다.

## 4. 체크리스트 시트 열 구성

| 열 | 항목 | 입력 방식 | 선택 값 |
|---|---|---|---|
| A | No | 자동 | 항목 입력 시 자동 부여 |
| B | 대분류 | 드롭다운 | 시스템 / 시설 / 행사 / 홍보 / 운영 |
| C | 중분류 | 드롭다운 | 무대, 소스, 기반, 렌탈, 연출, 개막식 등 25종 |
| D | 항목 | 직접 입력 | 원본 항목명 유지 |
| E | 세부내용 · 확인 포인트 | 직접 입력 | 원본 `내용` 열과 `CHK` 메모를 통합 |
| F | 필요여부 | 드롭다운 | 필요 / 불필요 / 검토중 |
| G | 진행상태 | 드롭다운 | 미착수 / 진행중 / 확인요청 / 완료 / 보류 / 해당없음 |
| H | 우선순위 | 드롭다운 | 상 / 중 / 하 |
| I | 수량 | 숫자 | |
| J | 단위 | 드롭다운 | 개, 동, 대, 식, 조, 명, 세트, 매, 장, 부, 회, 일, 박, 팀 등 |
| K | 담당 | 드롭다운 | `담당·업체` 시트 A열 참조 |
| L | 업체 | 드롭다운 | `담당·업체` 시트 E열 참조 |
| M | 마감일 | 날짜 | 예: 2026-10-01 |
| N | D-Day | 자동 | 마감일까지 남은 일수 (완료 시 "완료") |
| O | 예상비용(원) | 숫자 | 대시보드에서 합계 자동 집계 |
| P | 비고 | 직접 입력 | |

Q열에는 대시보드의 마감 임박 목록을 만들기 위한 정렬키가 자동 계산되며, 기본적으로 숨겨져 있습니다. 이 열은 수정하지 마십시오.

## 5. 자동화 기능

**대시보드**는 체크리스트 입력값만으로 전부 계산됩니다. 상단 핵심 지표에는 전체 항목 수, 관리 대상(불필요·해당없음 제외), 완료·진행중·미착수 건수, 지연 건수가 표시되고, 그 아래 전체 진행률이 백분율과 막대 형태로 함께 나타납니다. 이어서 진행상태별 집계, 대분류별 진행률, 담당별 배정·완료 현황이 표로 정리되며, 하단에는 우선순위 상 미완료 건수, 7일 내 마감 건수, 마감일·담당 미지정 건수, 예상비용 합계 및 완료 항목 비용이 요약됩니다. 우측 하단에는 **D-Day가 가장 급한 항목 8건**이 항목명·담당·상태와 함께 자동으로 나열되어, 매일 아침 확인용 브리핑 자료로 바로 쓸 수 있습니다.

**색상 경고**도 자동으로 작동합니다. 진행상태는 완료가 초록, 진행중이 노랑, 확인요청이 주황, 보류·해당없음이 회색으로 표시되고, D-Day 열은 마감이 지난 항목이 빨강, 3일 이내가 주황, 7일 이내가 노랑으로 강조됩니다. 우선순위 "상"은 붉은 굵은 글씨로 표시되어 우선 처리 대상이 눈에 즉시 들어옵니다.

## 6. 목록과 항목 추가 방법

드롭다운 선택지를 늘리려면 `설정` 시트의 해당 열 아래에 값을 이어서 입력하십시오. 각 목록은 200행까지 참조 범위가 미리 지정되어 있으므로 별도 설정 변경 없이 즉시 반영됩니다. 담당자나 업체를 추가할 때는 `담당·업체` 시트에 행을 추가하시면 됩니다.

새로운 점검 항목이 필요한 경우, `체크리스트` 시트의 119행 아래 빈 행(최대 300행)에 바로 입력하십시오. 이 구간에도 드롭다운과 D-Day 수식이 미리 적용되어 있어 별도 작업이 필요하지 않습니다.

## 7. Google 스프레드시트로 사용하기

Google 드라이브에 `행사_준비_체크리스트_자동화.xlsx`를 업로드한 뒤 파일을 더블클릭하고 상단의 **Google 스프레드시트로 열기**를 선택하면 변환됩니다. 변환 후에도 드롭다운은 [데이터] → [데이터 유효성 검사] 규칙으로, 조건부 서식은 [서식] → [조건부 서식]으로 그대로 남아 있어 편집과 공유가 자유롭습니다. 여러 담당자와 동시에 작업하실 경우 `체크리스트` 시트만 편집 권한을 부여하고 `대시보드`는 보호 범위로 지정하시면 수식이 훼손되지 않습니다.

함께 제공되는 `체크리스트_항목목록(백업).csv`는 항목 원본 목록의 순수 텍스트 백업입니다. 다른 도구로 목록을 옮기거나 새 파일을 처음부터 만들 때 활용하실 수 있습니다.
