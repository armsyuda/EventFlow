# 기존 자료 분석

## 자료 구성

| 파일 | 용도 | 반영 방식 |
|---|---|---|
| `행사_준비_체크리스트_자동화.xlsx` | 기존 자동화·대시보드 예시 | 화면과 기능 참고만 사용 |
| `체크리스트_항목목록(백업).xlsx` | 118개 항목 백업 | CSV와 대조 |
| `체크리스트_항목목록(백업).csv` | 정제 가능한 원본 목록 | 기본 항목의 기준 자료 |
| 사용 안내서 | 기존 업무 흐름 설명 | 상태·필드·집계 기준 참고 |

## 확인 결과

- 원본은 대분류 5개, 중분류 25개, 항목 118개다.
- 자동화 파일에는 시스템/무대의 `카메라다이`, `콘솔다이`가 추가되어 120개다.
- 자동화 파일의 빈 세부내용에 `81`이 99회 반복되며 행사정보 보조 셀에도 같은 값이 있다. 의미 있는 원본 데이터가 아닌 오염값으로 취급한다.
- 자동화 파일은 특정 행사 정보와 일부 수량·필요 여부가 입력된 사용 중 파일이다. 사용자 데이터 보존을 위해 원본 파일은 수정하지 않는다.
- 기존 수식은 외부 프로그램에서 `#NAME?`로 평가되는 항목이 있고, 300행까지 미리 만든 구조는 데이터와 화면을 과도하게 길게 만든다.

## 반영 결정

- CSV의 118개 항목에 추가 2개를 삽입해 120개 기본 항목을 만든다.
- 공백, `81`, Excel 수식·캐시 값, 기존 행사 입력값은 가져오지 않는다.
- 기존 대분류·중분류·세부 확인 포인트는 유지한다.
- 일정 오프셋은 별도 규칙으로 생성하고 프로그램의 기본 항목 화면에서 수정할 수 있게 한다.

## 기존 버전에서 유지할 장점

- 필요 여부와 해당없음을 진행률에서 제외하는 원칙
- 미착수·진행중·확인요청·완료·보류·해당없음 상태
- 담당·업체 마스터, 예상비용, D-Day, 마감 임박 목록

## 개선점

- 행사별 데이터를 독립 보관한다.
- 기본 항목 변경이 이미 생성된 행사에 소급되지 않게 스냅샷으로 저장한다.
- 업무 기간과 마감일을 모두 계산한다.
- 실제 데이터만 화면에 표시하고 검색·필터로 좁힌다.
- 수식 대신 테스트 가능한 Python 도메인 로직으로 계산한다.
