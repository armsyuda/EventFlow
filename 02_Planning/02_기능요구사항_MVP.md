# 기능 요구사항 — 현재 제품 (v0.3.29)

## 행사

- 행사명과 시작일은 필수, 종료일·장소(location)·주최/주관(organizer)·예산·예산 VAT 기준·PM 업체는 선택이다.
- 생성 마법사에서 기본 항목은 전체 선택되어 있고 대·중분류별 일괄 선택/해제가 가능하다.
- 행사 날짜를 바꿔도 기존 업무의 시작일·마감일은 다시 계산하지 않는다.

## 체크리스트

- 완료 체크박스와 `미착수/진행중/확인요청/보류/해당없음` 상태를 함께 사용한다.
- 완료 체크 시 상태가 완료가 되고, 완료 해제 시 미착수로 돌아간다.
- 상태, 수량, 단위, 담당, 업체, 시작일, 마감일, 비용, 메모를 수정한다.
- 시작일·마감일은 비워 둘 수 있다. 둘 다 있으면 시작일 ≤ 마감일이어야 한다.
- 검색 및 상태·대분류 필터를 제공한다.

## 대시보드

- 전체, 관리 대상, 완료, 진행중, 미착수, 지연, 진행률을 표시한다.
- 7일 이내 마감 및 지연 업무를 마감일 순으로 표시한다.
- 진행률 분모는 해당없음을 제외한 관리 대상이다.

## 달력

- 월간 달력에서 업무 기간에 해당하는 날짜를 표시한다.
- 날짜 선택 시 해당 날짜에 진행 중이거나 마감되는 업무를 행사·상태·기간과 함께 표시한다.

## 기본 항목·담당·업체

- 기본 항목의 분류, 이름, 확인 포인트, 수량, 단위, 기본 업체·담당을 관리한다. 기준일·오프셋 필드는 없다.
- 기본 항목을 추가하거나 삭제할 수 있다. 삭제해도 이미 생성된 행사의 작업 스냅샷은 보존한다.
- 담당자와 업체의 이름, 전화, 직책(job_title), 역할(role_note), 소속 업체를 관리한다. 이메일 컬럼은 없다.

## 저장·교환

- 변경은 즉시 SQLite에 저장한다.
- 앱 시작 시 하루 한 번 자동 백업하고 수동 백업·복원을 제공한다.
- 선택 행사 또는 전체 데이터를 Excel과 PDF로 내보낸다. CSV는 내보내지 않는다.
