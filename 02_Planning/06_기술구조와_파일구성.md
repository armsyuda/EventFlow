# 기술 구조와 파일 구성

## 기술

- Python 3.11+
- PySide6 Qt Widgets
- SQLite (`sqlite3`)
- openpyxl Excel 내보내기, PySide6 벡터 PDF 내보내기
- pytest 자동 테스트
- PyInstaller onedir Windows 배포

## 구조

```text
03_Program/
  src/event_checklist/
    app.py              실행 및 초기화
    config.py           데이터·백업 경로
    database.py         스키마와 질의
    services.py         업무 규칙
    backup.py           백업·복원
    export.py           Excel 출력
    pdf_export.py       PDF 출력
    theme.py            SEED 의미 토큰·QSS
    resources/          120개 기본 데이터
    ui/                 화면·대화상자·공통 위젯
  tests/
  tools/
  run.py
  pyproject.toml
```

## 사용자 데이터 위치

- DB: `%LOCALAPPDATA%/EventCheckList/data/event_checklist.db`
- 자동 백업: `%LOCALAPPDATA%/EventCheckList/backups`
- 이력: `%LOCALAPPDATA%/EventCheckList/history`
- 업데이트: `%LOCALAPPDATA%/EventCheckList/updates`
- 설치: `%LOCALAPPDATA%/Programs/EventFlow`
- 사용자가 지정한 수동 백업·내보내기 위치는 별도 선택

`schedule.py`와 CSV 내보내기 모듈은 없다.

개발·테스트에서는 `EVENT_CHECKLIST_DATA_DIR` 환경 변수로 격리된 임시 위치를 사용한다.

## 배포

Windows에서 PyInstaller onedir 패키지를 만든다. 데이터베이스는 실행 파일 옆이 아니라 사용자 데이터 폴더에 생성하여 업데이트 시 보존한다.
