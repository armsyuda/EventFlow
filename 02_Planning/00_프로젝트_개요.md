# 이벤트 체크리스트 자동화 시스템

## 목적

행사명과 시작일을 입력하고, 업무 시작일·마감일은 자동 계산하지 않으며 사용자가 직접 입력하거나 비우고, 체크리스트·달력·대시보드에서 진행 상황을 한눈에 관리하는 Windows 데스크톱 프로그램을 만든다.

## 대상 사용자

- 한 대의 Windows 10/11 PC에서 행사 준비를 총괄하는 기획·운영 담당자
- Excel 수식이나 데이터 구조를 몰라도 체크와 선택만으로 사용할 수 있는 사용자를 기준으로 한다.

## 현재 제품 범위 (v0.3.29)

- 행사 생성·수정, 시작일 필수·종료일 선택
- 120개 기본 항목 중 필요한 항목 선택
- 작업 시작일·마감일은 비워 둘 수 있으며 사용자가 직접 입력한다. 자동 일정은 v0.3.25에서 제거됨
- 체크박스 완료, 상태·담당·업체·비용·메모 관리
- 행사별 대시보드, 검색·필터, 월간 달력
- 기본 항목 및 담당·업체 관리
- SQLite 로컬 저장, 자동·수동 백업과 복원
- 행사 데이터 Excel(.xlsx)과 PDF 내보내기. CSV는 없다
- Python이 없는 Windows PC용 실행 패키지

## 제외 범위

로그인, 서버, 실시간 공동 편집, 댓글, 파일 첨부, 이메일·메신저 알림, 클라우드 동기화는 데스크톱 제품에 포함하지 않는다. 자동 일정과 CSV 내보내기는 현재 코드에 없다.

## 성공 기준

1. 새 행사를 3분 안에 만들고 선택한 항목이 즉시 생성된다. 일정은 자동으로 채워지지 않는다.
2. 앱을 닫았다 다시 열어도 모든 입력이 유지된다.
3. 해당없음 항목을 제외한 진행률과 지연 건수가 정확하다.
4. 백업 복원 및 Excel 내보내기가 사용자 조작으로 완료된다.
5. 1280×720 이상, Windows 배율 100~150%에서 주요 조작이 가능하다.
