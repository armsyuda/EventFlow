# 화면 구조와 사용 흐름

## 전체 구조

왼쪽 고정 내비게이션에 `대시보드`, `행사`, `달력`, `기본 항목`, `담당·업체`, `설정`을 배치한다. 오른쪽은 화면 제목, 설명/주요 동작, 본문 순서로 구성한다.

## 새 행사 생성

1. 행사 화면에서 `새 행사`를 누른다.
2. 행사명, 준비 시작일, 최종 행사일과 기본 정보를 입력한다.
3. 120개 기본 항목 트리에서 불필요한 항목을 해제한다.
4. 생성하면 항목 스냅샷과 자동 일정이 저장된다.
5. 생성된 행사가 선택되고 체크리스트가 열린다.

## 일상 사용

1. 대시보드에서 지연·임박 업무를 확인한다.
2. 행사 화면에서 완료 체크 또는 상태를 변경한다.
3. 달력에서 특정 날짜의 업무 기간을 확인한다.
4. 필요하면 담당·업체, 비용, 메모와 일정을 조정한다.
5. 표의 열 경계를 드래그하거나 `열 너비 맞춤`을 눌러 현재 창에 맞게 정리한다.

달력 날짜 셀에는 업무명 라벨을 최대 네 줄까지 표시한다. 미완료·마감일이 가까운 순서·기본 순서로 배치하고, 초과 항목은 `+N개 더보기`로 요약한다. 날짜 선택 시 오른쪽 목록에는 전체 항목을 표시한다.

## 빈 화면과 오류

- 행사가 없으면 설명과 `첫 행사 만들기` 버튼을 표시한다.
- 검색 결과가 없으면 필터 초기화 방법을 안내한다.
- 필수 입력 누락은 해당 입력 아래와 대화상자에 함께 표시한다.
- 복원·행사 삭제처럼 되돌리기 어려운 동작은 대상과 영향을 확인한 뒤 실행한다.
- 저장 실패는 조용히 무시하지 않고 오류 메시지와 데이터 위치를 표시한다.

## 키보드

- Tab/Shift+Tab으로 모든 입력과 버튼을 이동한다.
- Space로 체크, Enter로 기본 동작, Escape로 대화상자를 닫는다.
