# 구현 단계와 검증 기준

## 구현 단계

1. 자료 정제와 120개 기본 항목 생성
2. SQLite 스키마·저장소·일정 계산
3. 백업·복원·Excel/CSV 내보내기
4. SEED 토큰과 공통 UI
5. 대시보드·행사 체크리스트·달력
6. 기본 항목·담당·업체·설정
7. 자동 테스트와 Windows 패키징

## 자동 검증

- 기본 항목 120개, 오염값 `81/#NAME?` 없음
- 윤년·당일·다일 행사·종료일 기준 일정
- 선택한 항목만 생성되고 스냅샷이 유지됨
- 자동 일정 재계산, 수동 일정 보존
- 진행률 및 지연·임박 집계
- DB 재실행 영속성
- 백업 복원 전후 레코드 일치
- Excel/CSV 생성 및 대표 값 확인
- 오프스크린 GUI 시작·종료

## 수동 승인

- Windows 10/11 실제 PC 실행
- 1280×720, 1920×1080 및 배율 100/125/150% 확인
- 행사 생성부터 완료 체크, 달력 확인, 백업 복원까지 전체 흐름 확인
- 실행 파일 배포본에서 Python 미설치 PC 실행 확인
# 0.3.0 개편 구현 결과 (2026-08-11)

- 앱 명칭과 실행 파일을 `이벤트 플로우` / `EventFlow.exe`로 변경했다.
- 전용 상단바와 이플 아이콘을 적용하고 창 이동·최대화·최소화·닫기·가장자리 크기 조절을 연결했다.
- 시작 시 행사 미선택 대시보드를 표시하며, 선택 전에는 체크리스트·달력·정산내역을 비활성화한다.
- 설정을 기본 항목·업체/담당자·데이터 관리·앱 정보로 통합했다.
- DB v4, 기준/행사 단가, VAT, 참여 업체·프리랜서, 제외/복원, 일회성 항목과 정산 집계를 구현했다.
- 달력을 7열×6주 연속 타임라인으로 교체하고 대분류 색상, 동적 Lane, 더보기, 우측 목록 숨김을 구현했다.
- Excel에 상세 정산 및 대분류 소계·전체 비교 요약 시트를 추가했다.

- `event_checklist.pre-v3.db` 안전 복사본 생성 확인

- 패키징된 `EventFlow.exe` 신규 DB 및 사용자 DB 복사본 기동 종료 코드 0

## 0.3.1 입력 UI와 배포 자동화

- 업체·프리랜서 선택 영역을 행사 편집 창 높이에 맞춰 확대한다.
- 날짜 입력은 칸 클릭 즉시 달력을 열고, 모든 금액은 쉼표·원 단위를 표시하며 증감 화살표를 사용하지 않는다.
- 정산의 대분류 소계와 전체 합계를 서로 다른 강조색과 굵은 금액으로 구분한다.
- GitHub 태그 빌드가 `EventFlow-Windows.zip` Release를 만들고, 앱은 공개 최신 Release의 버전과 SHA-256 digest를 확인해 자동 설치한다.
- 자동 업데이트 테스트를 포함한 전체 자동 테스트 30개를 통과했다.
